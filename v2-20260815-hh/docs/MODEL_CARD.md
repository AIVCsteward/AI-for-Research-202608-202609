# 模型卡

## 用途

本模型用于 GOAI 虚拟细胞方向指定数据快照的酵母扰动蛋白质组条件响应预测，输出为 4,422 维 log2 蛋白强度。它是竞赛候选，不是临床、药物安全或机制因果推断工具。

## 最终候选

- 三专家：D0、S1 C、D2。
- 两个随机种子：20260814、20260815，权重各 0.5。
- metadata 新颖性路由固定，无药名特异规则。
- test 路由计数：D0 2,997；S1 C 1,322；D2 135。
- 预测尺度：log2；无裁剪、缩放或事后校准。

## 验证结果

- 四场景平均 RMSE：0.638989552855。
- 四场景平均 raw-FC PCC：0.304467385473。
- 两次独立推理最大差异：0.0。
- 最终 CSV：4,454 行、4,423 列，无 NA/inf。

以上均是本地验证或规划代理，`official_score=false`，不能当成官方榜单结果。

## 已知优势

- 层级批次分支在 plate/instrument 留出测试中优于 flat batch 与 no-batch，并具有显式 OOV 回退。
- 最终双 seed 均值比单 seed 更稳定，并在三套规划代理中排名第一。
- 对新化合物采用 D0 保守路由，避免将不稳定的 Morgan 迁移强行用于所有新药。
- 训练、验证、测试标签访问边界和 4,422 蛋白顺序有自动测试与哈希合同。

## 主要问题

- Matched Control 在绝对保真度上仍然很强，学习模型没有跨全部评分模块稳定超过它。
- Morgan 特征在 val_chem_only 有时改善，但在 val_both 可能负迁移；尚未证明稳健的真正新药泛化。
- 公开 validation/test 与 train 没有真正未见的技术批次 tuple，因此层级批次对独立内部新批次的泛化仍存在风险。
- FC 监督使用 `pert_id_parity_v1` 的非官方实验映射；正式 Water/DMSO 规则未获主办方确认。
- DHY210 使用 S288C 代理，不能解释为精确基因组等价。
- Tunicamycin 结构身份 unresolved；Oligomycin 使用 Oligomycin A 代理。

## 防泄漏

最终推理只读取 metadata、冻结外部特征、数据合同和 checkpoint，不读取 test proteome。外部特征标准化器只由训练实体拟合。
